🔥 S&P 500 Heatmap – Visualização de Performance Diária
Este projeto recria a experiência visual do Finviz.com, apresentando um heatmap interativo do S&P 500 que destaca a performance diária das maiores empresas do índice. Cada bloco representa uma empresa, com tamanho proporcional à capitalização de mercado e cor baseada na variação percentual do dia — verde para ganhos, vermelho para perdas.

A aplicação permite analisar rapidamente:

Tendências setoriais (Tecnologia, Saúde, Financeiro, Energia, etc.)

Sentimento do mercado num único dia

Movimentos relevantes como subidas fortes (ex.: AMD +7.68%, INTC +8.24%) ou quedas pontuais (ex.: MSFT -0.92%, WMT -1.46%)

Comparação visual entre empresas e setores

⚙️ Funcionalidades
Heatmap inspirado no Finviz

Agrupamento por setores

Cores dinâmicas conforme performance

Destaque automático para empresas com movimentos extremos

Layout responsivo e minimalista

📊 Objetivo
Fornecer uma ferramenta simples, rápida e visual para acompanhar a performance diária do S&P 500, ideal para analistas, criadores de conteúdo financeiro e entusiastas de mercados.

🚀 Tecnologias utilizadas
Python / Streamlit

Pandas

APIs financeiras

Estilo tech/minimalista
